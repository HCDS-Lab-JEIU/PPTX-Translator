# PPT Translator — UI 구현 명세

## 목표와 기술 방향
- 각 사용자가 자신의 PC에서 자신의 AI 계정으로 사용하는 PPT 번역·조정 도구.
- 권장 초기 구현: Python + PySide6 데스크톱 앱. 기존 저장소에 기술 선택이 있다면 먼저 확인하고 차이를 설명한다.
- 함께 제공한 layout-preview.html은 시각·상호작용 참고용이며 실제 AI, 계정, 파일 처리 기능은 없다.
- 예시 계정·모델·한도 수치를 실제 연결 정보처럼 표시하지 않는다.
- Web UI 채택 여부는 사용자와 논의 중이므로 프레임워크 전체 교체가 필요한 기존 프로젝트에서는 임의로 전환하지 않는다.

## 최종 화면 배치
권장 시작 크기 1440×960, 최소 크기 약 1100×760. 운영체제 배율 125~150%를 고려한다.
- 상단 툴바: 앱 이름 / 번역 방향 / AI 연결 관리 / 파일 추가 / 실행 시작.
- 본문 3열: 파일 목록 240px / 파이프라인 가변 폭 / 노드 속성 340px.
- 본문 QSplitter로 폭 조절. 속성창은 세로 스크롤 가능.
- 중앙 하단에 실행 로그. 본문 아래 전체 폭으로 작업 진행 영역, 맨 아래 상태바.
- 좌우 패널과 로그의 크기·접힘 상태를 저장한다.
- 미리보기의 좁은 폭 반응형 배치는 대화 내 표시를 위한 것. Qt에서는 QSplitter와 최소 크기로 대응.

### 왼쪽: 파일 목록
- 대기 / 완료 탭; 실행 중·실패 상태는 대기 목록 안에서 구분.
- 파일명, 슬라이드 수(분석 완료 시), 상태. 긴 파일명은 말줄임과 툴팁.
- 파일 추가 버튼과 드래그 앤 드롭으로 pptx 추가. 중복 여부 확인.
- 대기 파일 제거·순서 변경. 완료 파일은 결과 파일 열기·폴더 열기·재실행.
- 원본 덮어쓰기 기본 금지. 실행 전 출력 폴더 및 파일명 규칙 확인.
- 대기 파일이 없으면 추가 안내 표시.

### 중앙: 실행 파이프라인
- 기본 순서: PPT 텍스트 추출 → 번역 → 조정 → PPT 저장.
- 번역/조정 노드는 선택 가능. 선택 시 우측 속성 변경.
- 각 AI 노드에 연결 도구, 모델, 추론 수준 요약.
- 선택 표시와 실행 상태 표시를 분리: 선택=테두리, 상태=아이콘+텍스트.
- 상태: 준비 / 실행 / 완료 / 실패 / 건너뜀 / 일시정지.
- 첫 버전은 순서가 고정된 단순 파이프라인으로 구현 가능. 임의 분기·노드 에디터는 별도 요구 전까지 확장하지 않는다.

### 오른쪽: 노드 속성
공통 순서:
1. 선택 노드 이름·역할.
2. 실행 도구: Codex App Server / Gemini CLI / Antigravity CLI. Antigravity는 독립 어댑터로 구현하며, 모델·한도·이미지 읽기 연동 검증 후 활성화한다. 조회된 모델만 표시하고 이미지 검토는 앱에서 확인한 모델 계열로 제한한다.
3. 연결 계정 표시. 로그인은 앱 공통 연결 관리에서 수행.
4. 남은 한도: 이름, 남은 비율 또는 제공되는 단위, 막대, 초기화 시각, 마지막 갱신, 새로고침.
5. 모델 선택: 실제 연결에서 제공되거나 검증된 목록.
6. 추론 수준: 해당 모델이 지원하는 값만 표시. 미지원이면 숨김 또는 사유와 함께 비활성.
7. 노드별 작업 옵션.
8. 접을 수 있는 고급 설정: 프롬프트 등.

번역 옵션: 원본/대상 언어, 코드·수식 보존, 용어집.
PPT 저장 옵션: 파일 저장 위치, 파일 이름. 기본 파일명은 `원본 PPT 이름_최종언어.pptx`이며 UI의 `{stem}_{language}.pptx` 규칙으로 표현한다. 예: `강의자료_영어.pptx`. 파일별 미리보기를 제공하고 원본 경로와 동일한 출력은 금지한다. 기존 결과도 기본적으로 덮어쓰지 않는다.
조정 옵션: 텍스트 넘침·문장 길이, 용어·문체 일관성, 의미 보존, 기존 글자 크기 우선.
- 번역과 조정의 설정은 독립적으로 보관한다.
- 도구 변경 시 이전 모델/추론 값의 유효성을 재검증한다. 호환되지 않는 값은 초기화.
- 모델 목록 로딩/조회 실패/접근 가능 모델 없음 상태 제공.
- 실행 중 설정 수정은 다음 작업에 적용. 실행 중 파일에는 시작 시 확정한 설정 사용.

### AI 연결 관리
- 도구별 설치 확인, 실행 경로, 버전, 연결 계정, 공식 로그인·로그아웃, 연결 테스트.
- 비밀번호를 앱에서 직접 수집하지 않는다. 공식 인증 흐름과 해당 도구의 인증 저장소 활용.
- 인증 토큰·키를 로그나 프로젝트 설정에 남기지 않는다.
- 각 사용자의 OS 계정 아래에서 자신의 도구 프로세스를 실행한다.

### 남은 한도 표시 규칙
- 계정/제공되는 한도 버킷 단위로 상태를 공유. 노드별 독립 잔량으로 표현하지 않는다.
- 일정한 5시간/주간 한도를 가정하지 않고 응답의 window duration, 이름, reset timestamp에 맞춘다.
- usedPercent만 제공되면 remainingPercent=100-usedPercent. null은 0%가 아니다.
- 복수 버킷을 모두 표시. 버킷과 특정 모델의 관계를 확인하지 못했다면 계정 한도라고 명시.
- 상태: 조회 중 / 정상 / 오래된 정보 / 조회 불가 / 소진 / 미연결.
- 마지막 갱신 시간을 보존하고 이전 수치와 조회 실패를 구분.
- 로그인·도구 변경·작업 전후·수동 새로고침에서 조회. 도구가 제공하는 변경 알림도 사용.
- Codex 참고: account/rateLimits/read 및 account/rateLimits/updated.
- Gemini CLI/Antigravity는 실제 지원 방식 확인 전까지 정밀 잔량 조회를 보장하지 않는다. 추정값을 실제 잔량으로 표시하지 않는다.
- 한도 소진 시 완료 결과와 체크포인트를 보존하고 일시정지. 사용자 선택으로 초기화 대기 또는 다른 연결로 전환 후 미완료 단위부터 재개.
- 계정 한도와 현재 작업 토큰 사용량은 구분.

### 진행 영역 및 로그
- 전체: 완료 파일 수/전체 파일 수, 진행률.
- 현재 파일: 파일명, 처리 슬라이드 수, 현재 단계. 실제 측정 가능한 단위로 표시.
- 일시정지/재개/중지. 실행 상태에 따라 활성화.
- 로그: 시간, 파일, 단계, 상태, 오류와 재시도 사유. 자격증명 제외.
- 상태바: 준비/실행/일시정지/완료/실패 요약.

## PySide6 구현 매핑 (권장)
- QMainWindow + QToolBar + QStatusBar.
- QSplitter: 파일 목록 / 중앙 / 속성창.
- QTabWidget + QListView 또는 QTreeView: 파일 목록.
- 고정 파이프라인은 선택 가능한 QWidget 노드로 시작 가능. 이후 필요 시 QGraphicsView.
- QScrollArea + QFormLayout: 속성창.
- QComboBox: 도구·모델. QButtonGroup: 추론 수준.
- QProgressBar: 한도와 작업 진행률. 표시 단위 혼동 방지.
- QDialog: AI 연결 관리. QPlainTextEdit: 로그.
- QProcess 또는 비동기 작업 계층에서 외부 CLI 실행. GUI 스레드를 블로킹하지 않는다.
- UI와 PPT 처리, 작업 스케줄러, 도구 어댑터, 계정 한도 캐시를 분리한다.
- Provider 어댑터 공통 기능: 연결 상태 / 인증 / 모델 목록 / 지원 옵션 / 한도 / 작업 실행 / 취소.
- 지원되지 않는 기능은 명시적인 unavailable 상태로 반환.

## 구현 순서와 완료 기준
1. 모의 데이터로 배치·선택·설정 보존 구현. 스크린샷으로 확인.
2. 로컬 파일 큐와 처리 엔진 연결.
3. Codex 어댑터의 공식 인증/모델/한도/실행 연결.
4. Gemini CLI 어댑터 연결. 미지원 기능을 UI에 반영.
5. 취소·재시도·재개·원본 보존·오류 UI 확인.
- 노드를 오가도 각 설정이 유지된다.
- 같은 연결을 선택한 노드는 같은 한도 정보를 보여준다.
- 실패/미지원 상태에서 가짜 0% 또는 100%를 표시하지 않는다.
- 작업 중 창 이동, 노드 선택, 로그 확인이 멈추지 않는다.
- 원본 PPT와 텍스트 이외의 구조를 가능한 보존하고 미지원 요소는 명시한다.
