이 폴더의 UI_SPEC.md와 layout-preview.html을 읽고 PPT 번역 도구의 GUI를 구현해줘.

UI_SPEC.md는 기능과 상태 전이의 기준, layout-preview.html은 배치·색상·상호작용의 시각 참고다. HTML을 그대로 웹 앱으로 만드는 요청이 아니다.

우선 기존 저장소 구조와 AGENTS.md를 확인해라. 새 프로젝트라면 Python + PySide6 데스크톱 앱을 기준으로 진행하고, 기존 기술 스택과 충돌하면 변경 전에 차이를 설명해라.

첫 단계에서는 모의 데이터로 파일 목록, 파이프라인 노드 선택, 노드별 속성 보존, 계정 연결 관리 화면, 한도 상태, 진행 영역을 구현해라. 예시 값은 모의 데이터임을 명확히 해라. 그다음 실제 PPT 처리와 AI 어댑터를 연결해라.

각 사용자가 자기 PC에서 자신의 계정으로 로그인해 사용하는 구조여야 한다. 번역과 조정 노드에서 서로 다른 도구·모델·추론 수준을 지정할 수 있어야 한다. 로그인은 공통 연결 관리에서 수행한다.

Codex App Server, Gemini CLI, Antigravity CLI는 별도 어댑터로 분리하고, 실제 지원하는 모델·옵션·한도만 표시해라. Antigravity는 실제 모델·한도·이미지 읽기 검증을 통과한 범위에서 활성화한다. 세 도구의 자동 탐색은 터미널 PATH가 없는 GUI 실행도 고려한다. 인증 정보를 로그·프로젝트 파일에 저장하지 마라.

관련 공식 문서를 확인하며 구현하고, 지원 불명인 기능을 만들어냈다고 가정하지 마라. GUI를 블로킹하지 않게 하고 원본 PPT는 보존해라. 실행 및 확인 방법과 남은 미구현 부분을 함께 설명해라.
