# GUI 사용법

모든 명령은 프로젝트 루트에서 실행합니다.


기존 Python 파이프라인 위에 PySide6 데스크톱 화면을 추가했습니다. HTML은 시각 참고로만 사용하며 웹 서버나 브라우저 앱을 실행하지 않습니다.

```powershell
python -m pip install -r requirements-gui.txt
python app.py --demo  # 명시적인 모의 계정·모델·한도·파일, 실제 AI 호출/저장 없음
python app.py         # 이 PC의 사용자 계정으로 실제 작업
```

Python 3.10 이상이 필요합니다. 레이아웃 조정은 Windows PowerPoint를 사용합니다. `--demo`는 PowerPoint나 CLI 계정 없이 UI를 확인할 수 있습니다. 실제 파일을 데모에 추가해도 모의 실행만 하며 결과 PPT를 만들지 않습니다.

화면 배치는 `python app.py --demo`로 확인할 수 있습니다. 실행 중 GUI 스레드에서는 파일 분석·모델 호출·렌더링을 하지 않습니다. QThread 작업자에서 처리하고 Qt 신호로 화면을 갱신합니다.


## 작업 순서

1. 파일 추가 또는 드래그 앤 드롭으로 PPTX를 추가합니다. 중복 파일은 제외하며, 실행하지 않는 동안 제거·순서 변경이 가능합니다.
2. AI 연결 관리에서 설치 경로와 연결을 확인합니다. Codex는 공식 브라우저 로그인과 로그아웃을 제공합니다. Gemini는 공식 CLI의 인증 화면을 열고, 인증 완료 후 연결 테스트를 실행합니다. Gemini 연결 테스트는 실제 모델 호출을 1회 수행할 수 있습니다.
3. 번역·조정 노드의 도구·모델·추론 수준·프롬프트를 각각 설정합니다. 기본 GUI는 사용 가능 도구를 기준으로 Codex를 사용하며, 번역 medium / 조정 low를 선택합니다. 조회된 모델이 해당 값을 지원하지 않으면 지원 범위로 초기화합니다. Antigravity CLI도 독립 provider로 선택할 수 있으며 High/Medium/Low는 조회된 모델 이름에서 선택합니다.
4. PPT 저장 노드에서 위치와 이름을 지정합니다. 기본은 `output/exports/{stem}_{language}.pptx`이며 예를 들어 `강의자료_영어.pptx`가 됩니다. 여러 파일에 고정 이름을 지정해 충돌하거나, 원본 또는 기존 결과·보고서를 덮어쓰려 하면 실행을 막습니다.
5. 시작 전 출력 경로를 확인합니다. 처리 후 완료 탭에서 PPT나 폴더를 열 수 있습니다. 추가 검토가 필요한 결과도 완료 탭에 구분해 표시합니다.

모의 모드와 실제 모드의 계정·수치를 혼합하지 않습니다. 창 위치·패널 크기·로그 접힘 상태만 OS 사용자별 QSettings에 저장합니다. 계정 정보·인증 URL·토큰·키는 프로젝트 설정이나 로그에 저장하지 않습니다. Codex와 Gemini가 자체적으로 관리하는 인증 저장소를 사용하며, 앱이 자격증명 파일을 직접 읽거나 복사하지 않습니다. GUI 실행에서는 기존 CLI의 원본 RPC 이벤트 저장 기능을 사용하지 않습니다.

### 지원 범위와 상태

| 항목 | Codex App Server | 공식 Gemini CLI | Antigravity |
| --- | --- | --- | --- |
| 계정 연결 | 공식 브라우저 로그인/로그아웃 | 공식 CLI 인증 화면 열기·실제 연결 테스트 | 공식 CLI 열기 · 내부 인증/`/logout` 사용 |
| 모델 목록 | `model/list` 실제 응답 | `--model auto` 실제 호출 성공 후 자동 모드만 | `agy models` 실제 목록 |
| 추론 수준 | 해당 모델의 지원 목록 중 앱이 구현한 low~max | 검증 전 · 선택 비활성 | High/Medium/Low가 포함된 모델 slug 선택 · 별도 플래그 없음 |
| 계정 잔량 | `account/rateLimits/read` 및 변경 알림 | 정밀 조회 미지원 · 조회 불가 표시 | `/usage` 응답의 모델 그룹·잔량·리셋 시각 |
| 텍스트 번역 | 실제 연결 검증 | 어댑터 구현 · 현재 개발 PC에 CLI 미설치 | stream-json 실제 응답 검증 |
| 이미지 배치 검토 | `localImage` 첨부 · 실제 검증 | 이미지 도구 연동 미검증 · 조정 선택 제한 | Gemini 3.8 Flash 계열 · 성공한 이미지 열람 이벤트 필수 |

자동 탐색은 GUI 시작과 연결 관리의 설치·연결 조회에서 수행합니다. 수동 경로 또는 환경 변수(`CODEX_EXECUTABLE`, `GEMINI_CLI_EXECUTABLE`, `ANTIGRAVITY_CLI_EXECUTABLE`)를 우선하며, 명시한 경로가 잘못됐을 때 다른 도구로 임의 대체하지 않습니다. 경로를 비우면 자동 탐색으로 돌아갑니다. 찾은 경로는 연결 관리 입력칸과 상태에 표시하며, 자동으로 찾은 경로를 고정 수동 설정으로 저장하지 않습니다.

- Codex: PATH, 기본 설치 폴더, 사용자 VS Code/Insiders 확장에 포함된 native CLI, npm native vendor 경로.
- Antigravity: PATH, `%LOCALAPPDATA%/agy/bin/agy.exe`, 사용자 `.local/bin/agy`. PATH의 셸 래퍼는 native 설치 경로로 대체 탐색합니다.
- 공식 Gemini CLI: PATH, `%APPDATA%/npm`, Node.js 설치 위치. Windows npm 래퍼는 셸로 실행하지 않고 Node와 Gemini JS 진입점을 직접 연결합니다.

현재 PC에서 PATH가 있는 경우와 비어 있는 경우 모두 Codex와 Antigravity 자동 탐색을 확인했습니다. Codex의 실제 모델·한도 조회, Antigravity의 실제 모델 6개·한도 2그룹 조회 및 Gemini 3.8 Flash Low의 이미지 읽기 응답을 확인했습니다. 공식 Gemini CLI는 현재 PC에 없어 설치 안 됨으로 표시하며 가짜 모델·잔량을 채우지 않습니다. 인증 정보나 원본 RPC 응답은 GUI 프로젝트/로그에 저장하지 않습니다.

한도 수치는 동일 연결을 선택한 두 노드가 공유합니다. 응답에 있는 버킷·시간 구간·리셋 시각을 사용하며 고정 5시간/주간 창을 가정하지 않습니다. `usedPercent`는 남은 비율로 변환하지만 null은 미제공으로 남깁니다. 조회 실패 후 기존 값이 있으면 오래된 정보로 구분합니다. 모델과 버킷의 대응이 확인되지 않은 경우 모델별 잔량으로 표현하지 않습니다. Gemini CLI `/stats`의 세션 사용량을 계정 잔량으로 대체하지 않습니다.

일시정지는 현재 요청·렌더링 단위를 완료한 뒤 적용합니다. 중지는 실행 중인 모델 프로세스를 취소하고 저장된 번역·검토 결과를 보존합니다. PowerPoint 렌더링이나 파일 적용 중에는 해당 단위가 끝난 뒤 멈춥니다. GUI는 계속 반응합니다. 중지/실패 파일을 동일 설정으로 다시 실행하면 현재 앱 세션의 체크포인트부터 이어갑니다. "선택 파일 재실행"은 새 작업으로 시작합니다.

실행 중 속성 변경은 다음 파일에 적용합니다. 한도 초과로 대기할 때는 공식 연결 관리에서 문제를 해결하거나 도구·모델·추론 수준을 변경한 후 재개할 수 있습니다. 이때도 현재 파일의 언어·용어집·저장 경로 등은 시작 시 값을 유지합니다. 초기화 대기 후 수동 새로고침·재개를 사용하세요.

GUI 작업 파일은 선택한 출력 폴더의 `.pptx-work/<작업 ID>/`에 저장합니다. `checkpoint.json`, 추출/번역 데이터와 `document-layout/`의 전체 선별 보고서·JPG 비교 모음·상세 검토·수정 사본을 확인할 수 있습니다. 결과 옆 `<파일명>.report.json`에 미번역 페이지·미해결 레이아웃·압축 여부와 체크포인트 위치를 기록합니다. 상세 `.layout.json`에는 압축문과 대상 페이지·도형이 포함됩니다.

번역은 서식 표시나 일반 줄바꿈 때문에 원문으로 되돌리지 않고 가능한 한 번역문을 유지합니다. 의미별 서식 대응을 살릴 수 없으면 기본 서식으로 적용하고 복구 내역을 기록합니다. 숫자·수식 변경이나 번역 누락은 내용 오류이므로 재시도 후에도 해결되지 않으면 해당 원문을 유지합니다.

조정은 전체 미리보기에서 명확한 넘침·잘림·내용을 가리는 겹침·가독성 손상이 있는 페이지만 고릅니다. 읽기 좋고 영역 안에 맞는 두 줄 문장은 그대로 두며, 줄 수 증가·측정 누락·작은 미리보기의 불확실성만으로 수정하지 않습니다. 전체 선별이 실패해도 모든 페이지를 수정하지 않고 미검토 상태를 보고합니다. 조정 속성의 **필요한 문장만 의미를 유지하며 압축** 옵션은 기본으로 켜져 있으며, 표현 변경을 원하지 않으면 해제하세요. 수치·수식·서식 보호 검증을 통과한 짧은 표현만 적용하며 압축된 문장은 검토 필요로 기록합니다. 미리보기 선별의 정확도와 의미 보존은 모델의 판단에도 의존하므로 최종 결과를 확인하세요.


## 조정 없이 저장

조정 노드를 선택하고 속성에서 사용 여부를 해제하면 번역·적용 후 바로 저장합니다. 조정하지 않으면 PowerPoint 렌더링과 이미지 검토 AI 호출을 수행하지 않습니다.
